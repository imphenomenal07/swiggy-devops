# swiggy-devops
This the code and infra repo for swiggy clone application

# Tech Stack:

Terraform, AWS, Github, Docker, Kubernetes, Jenkins, Trivy, SonarQube & Owasp

# Pipeline flow

Terraform ➡️ AWS ➡️ GitHub ➡️ Jenkins ➡️ SonarQube ➡️ Owasp ➡️ Trivy ➡️ Docker Image ➡️ Trivy ➡️ Docker Conatiner ➡️ Final App
